# Face Recognition System using OpenCV, Python & MySQL

This project implements a Face Recognition System using OpenCV and Python.
It captures face images, trains a recognition model, and identifies users.
User details are stored and managed using a MySQL database.

## 🚀 Features
- Face detection using Haar Cascade
- Face recognition using LBPH algorithm
- MySQL database integration
- Real-time face recognition via webcam

## 🛠 Technologies Used
- Python
- OpenCV
- MySQL
- NumPy

## 📂 Project Structure
- `dataset/` – Face image data
- `models/` – Trained models and Haar cascade files
- `src/` – Python source code
- `database/` – MySQL database scripts
